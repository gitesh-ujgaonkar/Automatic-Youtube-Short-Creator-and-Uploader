# Automatic YouTube Short Creator & Uploader 🎬🤖

Welcome to my auto-shorts generator! This project automate the entire process of creating and uploading YouTube Shorts. Its designed to run completely hands-free once you set it up. I built this because I wanted a pipeline that handles everything from the idea generation to the final video upload without me having to edit anything manually.

## What it does (The non-technical version)
Basically, the script thinks of a random interesting topic, writes a short script, generates AI images for the scenes, stitches them together with audio and subtitles, and then uploads the final video to your YouTube channel. You just run the script and go grab a coffee.

## Technical Details ⚙️
Under the hood, this script take care of a lot of moving parts:
- **LLM & Scripting:** Uses the Groq API (dynamically selecting models like `openai/gpt-oss-120b`) to generate short video scripts and JSON storyboards.
- **Visuals:** Uses Pollinations.ai to generate flat vector art images on the fly based on the LLM's prompts.
- **Audio & Video Compilation:** Uses FFmpeg to compile the images, add the voiceover, and render the final MP4 with subtitles.
- **YouTube Upload:** Uses the Google YouTube Data API v3 to upload the video securely via OAuth2.0.

## Prerequisites
Before you run this in your enviornment, you will need a few things:
1. **Python 3.10+**
2. **FFmpeg** installed on your system.
3. A **Groq API Key** (set as an environment variable).
4. **Google Cloud Console Credentials:** You need a `client_secrets.json` file from a Google Cloud project with the YouTube Data API enabled.
5. **`token.json`:** Generated by authenticating your Google account locally (we have a separate auth script for this).

## How to Run it

1. **Clone the repo and install dependencies:**
   ```bash
   git clone https://github.com/gitesh-ujgaonkar/Automatic-Youtube-Short-Creator-and-Uploader.git
   cd Automatic-Youtube-Short-Creator-and-Uploader
   pip install -r requirements.txt
   ```

2. **Add your secrets:**
   - Put your `client_secrets.json` in the root folder.
   - Generate your `token.json` and place it in the root folder too.

3. **Run the magic:**
   ```bash
   python master_pipeline.py
   ```

If everything configure right, you will see the terminal output the steps (script generation, image fetching, video rendering) and eventually a success message with your YouTube link!

## Notes
- The code includes fallback mechanisms in case an image fails to generate or an LLM model gets deprecated.
- Make sure your YouTube API quota is sufficient if you plan to run this multiple times a day.
